# 📚 Trivia Project (Client–Server Game)

> Developed as part of the **Magshimim Cyber Education Program** 🇮🇱  
A fully-featured multiplayer **client-server trivia game** designed to support authentication, game rooms, scoreboards, and interactive gameplay.

## 🚀 Features

- 🔐 **User Authentication**  
  Sign-up and login with secure credential checks

- 🧠 **Trivia Game Engine**  
  Multiplayer rooms with unique questions per session

- ⏱️ **Timers & Answer Validation**  
  Automatic handling of timeouts, scoring, and correct answer checks

- 📋 **Room Management**  
  Host and join trivia game sessions with multiple players

- 📊 **User Statistics & Leaderboards**  
  Track wins, losses, and total points with rankings

- 💬 **Client–Server Communication**  
  Custom TCP protocol with JSON messages for efficient messaging
## 🛠️ Tech Stack

| Layer             | Technologies                           |
|------------------|----------------------------------------|
| 👨‍💻 Client UI       | `C# (WPF)`
| 🧠 Sקהקר             |   `C++`     
| 🌐 Networking      | `TCP Sockets`, Custom Protocol        
| 📦 Message Format  | `JSON`                                
| 🗃️ Database         | `SQLite` (for users,questions,players statistics)
